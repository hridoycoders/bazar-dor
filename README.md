# 🛒 বাজার দর (BazarDor)

A responsive Bangla web application for checking everyday product prices and comparing market rates.

## Features

- Responsive design for mobile, tablet, and desktop.
- View product prices and market comparisons.
- Browse products by category.
- Dynamic product details pages.
- User authentication with Better Auth.
- User profile and profile update.
- Loading states and error handling.
- Custom 404 page.
- Bengali date and price ticker.

## Technologies Used

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- MongoDB
- Better Auth
- React Hot Toast

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm run start
```
